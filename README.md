# MojaAplikacjaMvc

Prosta aplikacja ASP.NET Core MVC z interaktywnym schedulerem wydarzeń.

## Uruchomienie

Wymagany jest .NET 8 SDK. W katalogu projektu wykonaj:

```bash
dotnet run
```

Następnie otwórz adres podany w konsoli.

## Scheduler

Widok główny pokazuje kalendarz z zasobami (sale i osoby), wydarzeniami, nawigacją między miesiącami oraz możliwością zwijania grup. Dodaj wydarzenie przyciskiem „+ Dodaj wydarzenie” albo dwukrotnym kliknięciem wolnego pola w wierszu zasobu.
